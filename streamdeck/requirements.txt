# Stream Deck controller dependencies. This file is the one place these pins
# live; firstboot.sh installs from it and only falls back to an inline list
# when the repo is not checked out yet.
# Install into the same environment that runs the controller:
#   pip install -r streamdeck/requirements.txt
#
# Every pin is a range: the controller updates by git pull, so a floor with a
# next-major ceiling lets patch releases reach a deployed device while a
# breaking major never does.

# Pure-Python driver for Elgato Stream Deck / Stream Deck Module hardware.
# 0.9.8 is the floor: it adds the USB product id 0x00ba used by current XL /
# Module 32 hardware revisions. Older releases report "no Stream Deck found"
# for those decks even though the kernel enumerates them.
streamdeck>=0.9.8,<1

# Key image rendering. The floor follows Pillow's image-decoder security
# fixes, because the deck decodes camera snapshots fetched over the network:
# 13.0.0 on Python 3.11 and newer. Pillow 13 needs Python 3.11, so Python 3.10
# (Ubuntu 22.04) stays on 12.x from 12.3.0.
Pillow>=13.0.0,<14; python_version >= '3.11'
Pillow>=12.3.0,<13; python_version < '3.11'

# HTTP client for the FoodAssistant API.
httpx>=0.27.0,<1

# WebSocket client for Chrome DevTools Protocol (kiosk navigation).
websockets>=17.3,<18

# TOML config reader for Python 3.10 (Ubuntu 22.04). Python 3.11 and newer
# ship tomllib in the standard library, so this installs only on 3.10.
tomli>=2,<3; python_version < '3.11'
