{# Two-pane split view for ultrawide and tall kiosk panels (FoodAssistant-dqpq). A standalone wrapper (no base.html): two same-origin iframes share the display, side by side in landscape and stacked in portrait, so a bar panel like the Waveshare 480x1920 can keep Glance up on one half while the other half browses the full app. Navigation inside a pane stays inside that pane naturally; the wrapper itself never navigates. A locked first pane snaps back to its page whenever something carries it away, so it holds as an always-on status panel. The screensaver and the kiosk idle reporter load HERE, on the wrapper, so the saver overlays the whole display above both panes; the framed pages' own screensaver.js stands down inside a frame. Because iframe input never bubbles to the wrapper, a small relay below forwards pane activity so the wrapper's idle countdown resets while someone is using either pane. Like start.html this page must carry the kiosk display attributes itself. data-ui-scale is pinned to 1.0 ON PURPOSE: each pane's page applies the configured interface scale to its own content, so scaling the wrapper too would compound the zoom and push the panes off screen. #} Split View: Pantry Raider {# Latches kiosk mode from ?kiosk=1 and applies rotation plus the panel safe-area insets to this standalone page (FoodAssistant-2e0f). #}
