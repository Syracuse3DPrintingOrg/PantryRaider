Bandit Cubs

A Bandit Cub is a small ESP32 screen that sits on a counter, a fridge door, or by the stove and shows what your kitchen needs right now: items about to expire, running timers, and thermometer probes. What it shows is decided here on your server, not on the device, so you never reflash to change it. A Cub listens to a status broadcast your kitchen sends over Bluetooth, so there is nothing to pair: turn the broadcast on, plug the Cub into this computer over USB, and flash it below.

What happens next
  1. Turn on Broadcast kitchen status over Bluetooth in Settings, Bandit Remotes, under Bandit Cubs. It is off until you do. The broadcast comes from a device with a Bluetooth radio that runs the thermometer reader, such as a Pi appliance or a Bandit. A Docker or Unraid server usually has no Bluetooth radio, so on its own it cannot drive a Cub.
  2. Plug the Cub into this computer over USB and click Install on its board above.
  3. If you like, set the Cub's Wi-Fi right here in the browser when it asks. A Cub does not need Wi-Fi to work; it only adds the Home Assistant sensors and logs.
  4. The Cub shows your kitchen as soon as it hears the broadcast. The first broadcast it hears is the one it keeps, unless its firmware was built to listen to one install only (see A different board below).
No Chrome or a locked-down browser?

The browser flasher needs Chrome or Edge over a secure (HTTPS) address. If that is not you, download the firmware for your board above and flash it with the esptool command shown, or use web.esphome.io, a browser flasher that works from any HTTPS page (upload the same downloaded firmware file there).

A different board

A Cub is a standard ESPHome project, so any ESP32 board can be one: the firmware here is built from the esphome/ folder in the project repo. Copy the profile YAML closest to your board and build it in your own ESPHome dashboard. It needs no server address and no key. To make the Cub listen to this kitchen only, set pr_install_tag to the install tag shown in Settings, Bandit Remotes, under Bandit Cubs. The three boards above are the ones with prebuilt one-click images; everything else takes this route for now.
